# AI 学习伴侣（纯本地）

纯本地运行的 AI 学习伴侣：通过鼠标轨迹、屏幕截图等多维信号实时感知学习者的认知状态（卡壳、过度自信、易混淆概念、薄弱题型），并提供个性化干预（动态难度、变体题、RL Boss）。

> 全局上下文锚点见 [AI_CONTEXT.md](./AI_CONTEXT.md)，任何模块开发前必须通读。

## 运行环境

- Python 3.10+
- Windows 10/11，Intel Core Ultra 9（含 NPU）+ Intel Arc 显卡，32GB RAM
- 训练后端：torch-directml（优先）→ CPU 回退，无需 NVIDIA GPU

## 三行快速启动

```bash
pip install -r requirements.txt
py -3.12 -m backend.app          # 启动本地服务（默认 http://127.0.0.1:8000）
py -3.12 -m tests.smoke.smoke_p0 # 运行 P0 冒烟测试
```

## 当前论文核心功能

本阶段汇报论文聚焦**两个核心功能**（其余为"未来扩展"愿景）：

- **文章关键词提取**：文章 → 统计层候选(TextRank+PMI) → 语义层精排 → 梯度提升重排 → Top-N 关键词。独立 27 篇测试集：Hit@1 89%（规则基线 81%）、Gold 召回 0.75（规则 0.70）。
- **读题划词**：读题/审题双模式。读题划词 → 提交后按「命中/漏划/多余」三色高亮并逐词讲评；判定口径＝学生划词 vs 该题保存的标准关键词。分学科 holdout：数学 0.938、语文 0.803。审题题库在 `data/readingbank/{物理,语文}.jsonl`。

## 功能优先级

- **P2（有余力做）**：F1-3、F3-3、F7-1/F7-2
