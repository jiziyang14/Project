# frontend（纯静态前端）

本目录职责：用户界面，采用玻璃质感设计（Design.md），HTML/CSS/JS 完全分离。
全局上下文见 ../../AI_CONTEXT.md。

| 文件 | 职责 |
|-|-|
| `index.html` | DOM 骨架，无内联 style/script |
| `css/main.css` | 玻璃材质、信号色、布局（Design.md 令牌） |
| `js/api.js` | 本地后端 API 封装 |
| `js/ui.js` | 自定义弹窗组件（禁用原生 alert） |
| `js/main.js` | 主入口：交互与数据加载 |

## 规范要点

- 纯静态，无构建工具；ES6 模块。
- 仅请求本地 127.0.0.1:8000，无任何外部网络。
- 所有反馈用自定义弹窗，禁用浏览器原生控件。

## 功能要点

- **答题 / 审题双模式合一**：同一读题界面一键切换作答与审题；审题模式下按该题标准划词把学生划词归为命中/漏划/多余，并对题面做三色高亮（命中绿 / 漏划橙 / 多余灰），提交或完成审题后统一揭示，不提前剧透。
- **审题题库筛选**：经 `/api/readingbank/random` 按学科/难度/题型抽题（题源 data/readingbank/{物理,语文}.jsonl），每题带标准划词，可增删关键词并回写。
- **读题划词三色讲评**：题干/选项支持 LaTeX 公式渲染，逐词高亮讲解"该不该划"。
- **标注与训练工作台**：文章关键词 ↔ 读题划词两套标注共用同一工作台，可导出训练数据、一键训练与评估（重排模型 / 划词模型）。

## Quick Run

启动后端后访问 http://127.0.0.1:8000 即可。
