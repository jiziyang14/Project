# 项目需求文档



## 一、项目概述

### 1.1 项目背景

传统学习系统仅根据答题对错进行评价，无法捕捉学习过程中的认知摩擦点。本系统旨在构建一个纯本地运行的AI学习伴侣，通过鼠标轨迹、屏幕截图等多维度信号，实时感知学习者的认知状态，并提供个性化干预。

### 1.2 核心设计思想

1. **用户主导**：所有采集模块由用户逐项开启，不强制运行
2. **多途径录入**：框选OCR、手动粘贴、拍照上传三种方式
3. **题目与错题分离**：聚类功能对全量题目有效，错因分析仅对错题有效
4. **深度学习驱动**：核心感知与诊断模块基于PyTorch可训练模型

### 1.3 核心目标

* **感知**：从鼠标、截图中提取可量化的认知状态特征（用户可选开启）
* **录入**：支持多种方式将题目录入系统（框选OCR/粘贴/拍照）
* **诊断**：识别卡壳、过度自信、易混淆概念、薄弱题型等认知问题
* **干预**：通过动态难度调整和变体题生成，实现个性化学习对抗

### 1.4 技术约束

* **严禁调用**任何云端或本地大语言模型API
* **纯本地运行**，所有模型推理和训练均在本地完成
* **深度学习优先**：核心感知与诊断模块必须基于可训练的PyTorch模型
* **运行环境**：Windows笔记本，GPU可用，无需联网
* **OCR引擎**：PaddleOCR 或 Tesseract（本地离线版，用户可选启用）



## 二、核心概念定义

### 2.1 题目 vs 错题

|概念|定义|数据来源|用途|
|-|-|-|-|
|**题目**|用户录入系统的任意一道题（无论对错）|用户通过OCR/粘贴/拍照录入|F2-6题型聚类、F2-3语义混淆、F5-2变体生成|
|**错题**|用户做错的题目（是题目的子集）|用户在做完一道题后判定为“答错”并标记|F2-4错因聚类、F4-2难度评估、F4-3自信检测、F5-1 Boss更新|

**关系图**：

```
用户录入的题目（全量题库）
    ├── 已掌握（答对）
    │       ↓
    │  参与F2-6题型聚类
    │  参与F2-3语义混淆
    │
    └── 错题（答错）
            ↓
       参与F2-6题型聚类（同左）
       参与F2-3语义混淆（同左）
       额外触发：
         F2-4错因聚类（基于错误答案）
         F4-2个性化难度预测
         F4-3过度自信检测
         F5-1 RL Boss更新
```

### 2.2 两个聚类的分工

|维度|F2-6 题型聚类|F2-4 错因聚类|
|-|-|-|
|聚类对象|题目题干（全量题库）|错误答案（仅错题）|
|输出结果|题型类别（如“力学计算类”）|错因类别（如“逻辑断裂型”）|
|回答的问题|“哪种类型的题我做得最多/少？”|“我做错时主要犯什么类型的错误？”|
|依赖状态|所有已录入题目|仅答错的题目|
|触发条件|题库 ≥ 5 道题|错题库 ≥ 5 道且含错误答案文本|



## 三、用户交互逻辑（完整流程）

### 3.1 系统启动与模块开启

```
用户双击启动系统
        ↓
系统显示主界面，所有功能模块默认关闭
        ↓
用户根据需要逐项开启功能：
  ☐ 鼠标轨迹采集（F1-1）—— 用于卡壳预判
  ☐ 屏幕截图采集（F1-2）—— 用于注意力曲线
  ☐ 读题划词记录（F1-4）—— 用于读题策略分析
  ☐ OCR识别引擎（为题目录入服务）
        ↓
用户开始学习，系统在后台静默运行已开启的模块
```

### 3.2 题目的三种录入方式

用户可在任意时刻点击【添加题目】，选择以下方式之一：

#### 方式一：框选OCR识别（推荐，P0）

```
用户点击【添加题目】→ 选择【OCR识别】
        ↓
屏幕进入“框选模式”（屏幕变暗，出现十字光标）
        ↓
用户按住鼠标左键拖拽，框选题目所在矩形区域（仅题干+选项）
        ↓
释放鼠标，系统调用PaddleOCR对该区域执行文本识别
        ↓
识别结果呈现在表单中（题干+选项分开），用户可编辑修正
        ↓
用户补充填写：
  - 正确答案（必填）
  - 知识点标签（可选，系统自动推荐）
  - 是否错题（如已做过且答错）
        ↓
点击【保存题目】→ 题目进入系统题库
```

#### 方式二：手动粘贴录入（P0）

```
用户点击【添加题目】→ 选择【手动录入】
        ↓
显示表单，用户自行填写：
  - 题目文本（必填）
  - 选项（可选）
  - 正确答案（必填）
  - 知识点标签（可选）
  - 是否错题（如已做过且答错）
        ↓
点击【保存题目】→ 题目进入系统题库
```

#### 方式三：拍照上传（P1）

```
用户点击【添加题目】→ 选择【拍照上传】
        ↓
系统生成二维码，手机扫码后打开拍照页面
        ↓
用户手机拍摄纸质题目照片，上传至电脑
        ↓
电脑端接收图片，调用OCR识别并提取题目文本
        ↓
识别结果呈现在表单中，用户确认/修正后保存
```

### 3.3 答题与错题判定流程

```
用户从题库中选择一道题 → 点击【开始答题】
        ↓
系统展示题目内容
        ↓
用户阅读并作答（在系统界面中选择答案或输入答案）
        ↓
用户点击【提交答案】
        ↓
系统弹窗：“这题你有把握吗？”【确定】/【蒙的】
        ↓
用户选择后，系统提示“正确答案是：\\\[答案]”
        ↓
用户确认：
  【我做对了】→ 标记为“已掌握”，结束
  【我做错了】→ 标记为“错题”，进入错题库
        ↓
触发错题分析流程（自动执行）：
  - F4-2 专属难度预测
  - F4-3 过度自信检测（若>0.7则弹窗）
  - F2-4 错因聚类增量更新
  - F5-1 RL Boss状态更新
  - F6-1 关联图谱累积
```

### 3.4 文章分析模块（独立，P0）

```
用户点击【文章分析】
        ↓
选择上传方式：
  - 粘贴纯文本
  - 上传 .txt / .md / .pdf 文件
        ↓
系统使用KeyBERT提取中心词（F2-5）
        ↓
展示 Top 5-10 中心词及权重
        ↓
用户可选择【加入语义库】（供F2-3混淆推理使用）
```

### 3.5 语音分析模块（独立，P2）

```
用户点击【语音分析】
        ↓
选择方式：
  - 【开始录音】→ 讲题 → 【停止录音】
  - 【上传文件】→ 选择音频文件
        ↓
系统使用Whisper-tiny转写并检测卡壳
        ↓
展示转写文本 + 卡壳时间戳标记
```



## 四、功能模块详细规格

### 4.1 数据采集层（L0）

|编号|功能名称|描述|触发方式|训练/推理|优先级|
|-|-|-|-|-|-|
|F1-1|鼠标轨迹采集|每秒记录(x,y,时间戳)，滑窗50帧形成`\\\[batch,50,3]`张量|用户勾选开启|纯采集|P0|
|F1-2|屏幕截图采集|每500ms截屏，压缩至224×224，缓存2000张|用户勾选开启|纯采集|P0|
|F1-3|麦克风录音|用户点击开始/停止，录制为16kHz WAV|用户点击触发|纯采集|P2|
|F1-4|读题划词顺序记录|记录高亮/划选顺序，形成不定长one-hot序列|用户勾选开启|纯采集|P1|
|F1-5|错题与自评入库|存储错题题干、错误答案、自评、耗时、犹豫次数|答题判定错误自动触发|纯存储|P0|

**F1-1 详细规格**：

* 采集频率：1 Hz
* 滑窗大小：50帧
* 输出张量：`\\\[batch, 50, 3]`（x归一化，y归一化，时间差）
* 存储格式：按session分文件，JSON Lines格式

**F1-2 详细规格**：

* 采集频率：2 Hz（每500ms）
* 图像尺寸：224 × 224 × 3（RGB）
* 缓存容量：2000张（约1.2GB内存）
* 存储策略：仅内存队列，不落盘

### 4.2 题目录入层（L0-Entry）

|编号|功能名称|描述|技术实现|优先级|
|-|-|-|-|-|
|F0-1|框选OCR识别|用户框选屏幕区域，OCR提取题目文本|PaddleOCR + 鼠标框选UI|P0|
|F0-2|手动粘贴录入|用户复制粘贴题目文本及正确答案|纯表单|P0|
|F0-3|拍照上传录入|手机拍照上传图片，OCR识别|PaddleOCR + 临时图片服务器|P1|

**F0-1 详细规格**：

* OCR引擎：PaddleOCR（PP-OCRv3，轻量级）
* 识别延迟：< 2秒（框选后到表单填充完成）
* 输出结构：`{question\\\_text, options: \\\[], correct\\\_answer: ""}`
* 容错：识别结果可编辑修正

### 4.3 内容语义层（L1）

|编号|功能名称|描述|处理范围|训练/推理|优先级|
|-|-|-|-|-|-|
|F2-1|线索词悬停权重统计|统计关键词悬停时长，输出认知摩擦指数|全量题目|纯规则|P1|
|F2-2|反常识词对挖掘|从题目文本挖掘语义对立词对（如光滑vs粗糙）|全量题目|纯规则|P1|
|F2-3|易混淆语义推理|SBERT嵌入知识点，计算相似度并生成辨析提示|全量题目|预训练推理|P0|
|F2-4|错误原因聚类|将错题的错误答案聚类为错因类型|仅错题|预训练推理+聚类|P1|
|F2-5|文章中心词提取|用户提交文章，KeyBERT提取Top 5-10中心词|用户提交的文章|预训练推理|P0|
|F2-6|题型语义聚类|将全量题目题干按题型分组|全量题目|预训练推理+聚类|P0|

**F2-3 详细规格**：

* 模型：Sentence-BERT（all-MiniLM-L6-v2）
* 嵌入维度：384
* 核心算法：`cosine\\\_similarity` + `emb(A) - emb(B) + emb(C)` 向量类比
* 输出：易混淆词对 + 辨析提示文本
* 知识库来源：用户录入题目的知识点标签 + F2-5中心词（用户选择加入后）

**F2-4 详细规格**：

* 模型：Sentence-BERT嵌入 + DBSCAN聚类
* eps：0.5，min\_samples：3
* 输出标签：逻辑断裂型 / 前提误解型 / 天马行空创新型
* 触发条件：错题库 ≥ 5 道且含错误答案文本

**F2-5 详细规格**：

* 算法：KeyBERT（基于Sentence-BERT的深度语义关键词提取）
* 备选：TextRank 图排序融合（提升稳定性）
* 输出：Top 5-10 中心词 + 权重（0\~1）
* 性能：1000字以内 < 20秒
* 下游：用户可选择将中心词加入F2-3语义空间

**F2-6 详细规格**：

* 模型：Sentence-BERT嵌入 + K-Means聚类
* K值确定：轮廓系数自动确定（范围3\~8）
* 簇命名：TF-IDF提取簇关键词拼接
* 输出：每个题目的题型簇ID + 各簇占比 + 各簇代表题
* 触发条件：题库 ≥ 5 道题
* 更新：每次新增题目时增量更新

### 4.4 行为与视觉感知层（L2）

|编号|功能名称|描述|前置条件|训练/推理|优先级|
|-|-|-|-|-|-|
|F3-1|鼠标走神预判|Transformer输入鼠标轨迹，输出“流畅/犹豫/卡壳”|用户开启F1-1|**训练+推理**|P0|
|F3-2|截图注意力监测|ResNet+对比学习输出相邻帧相似度曲线|用户开启F1-2|**训练+推理**|P0|
|F3-3|语音卡壳检测|Whisper转写音频，提取卡壳时间戳|用户主动提交音频|预训练推理|P2|

**F3-1 详细规格（Transformer）**：

* 模型架构：2层Transformer Encoder

  * d\_model：64，nhead：4，dim\_feedforward：128
  * 位置编码：可训练
  * 输出头：分类头（64→3）
* 输入：`\\\[batch, 50, 3]`（鼠标x, y, 时间差）
* 输出：三类概率（流畅/犹豫/卡壳）
* 训练数据：200条手动标注轨迹片段
* 训练耗时：GPU约10分钟
* 特殊产出：可提取注意力权重矩阵绘制“自注意力热力图”
* 推理延迟：< 100ms

**F3-2 详细规格（ResNet+对比学习）**：

* 模型架构：ResNet-18（冻结前7层）+ 投影头（512→128→64）
* 训练范式：SimCLR自监督对比学习
* 正样本对：相邻帧（间隔0.5s）
* 负样本对：随机间隔 > 30秒的两帧
* Loss：InfoNCE（温度系数0.07）
* 训练数据：2000张截图
* Batch Size：64
* 训练耗时：GPU约30分钟
* 输出：相邻帧余弦相似度时序曲线 + 死机式学习检测（连续10分钟变化率极低）

### 4.5 认知诊断层（L3-Diagnosis）

|编号|功能名称|描述|处理范围|训练/推理|优先级|
|-|-|-|-|-|-|
|F4-1|读题策略分类|LSTM识别划词顺序，输出读题策略类型|全量题目（需开启F1-4）|**训练+推理**|P1|
|F4-2|个性化难度预测|MLP回归器输出专属难度值（0\~1）|仅错题|**训练+推理**|P1|
|F4-3|过度自信检测|MLP融合特征输出盲目自信概率|仅错题|**训练+推理**|P0|
|F4-4|变体题有效性判别|MLP判断变体题是否值得推送|全量题目|**训练+推理**|P1|

**F4-1 详细规格（LSTM）**：

* 模型架构：1层LSTM（input\_size=词汇表大小，hidden\_size=64）
* 输出：3分类（数据优先型/逻辑优先型/跳跃型）
* 训练数据：50条手动标注划词路径
* 训练耗时：GPU约5分钟

**F4-2 详细规格（MLP回归）**：

* 输入特征：3维（耗时/平均耗时，退格爆发次数，鼠标犹豫计数）
* 模型架构：3层MLP（3→16→1，ReLU）
* Loss：MSE
* 训练标签：历史正确率映射（正确=0.2，错误=0.8）
* 训练数据：300条历史记录
* 训练耗时：GPU约3分钟

**F4-3 详细规格（MLP分类）**：

* 输入特征：4维（自评0/1，犹豫次数，难度值，耗时/平均耗时）
* 模型架构：3层MLP（4→32→16→1，Sigmoid）
* Loss：BCE
* 训练标签：做错且自评=1 → 正样本
* 训练数据：300条历史记录
* 训练耗时：GPU约10分钟
* 阈值：输出 > 0.7 触发弹窗警告

**F4-4 详细规格（MLP分类）**：

* 输入特征：384维（原题SBERT嵌入 - 变体题SBERT嵌入）
* 模型架构：2层MLP（384→32→1，Sigmoid）
* Loss：BCE
* 训练标签：50对人工标注（有效/无效）
* 训练耗时：GPU约5分钟

### 4.6 智能干预层（L3-Intervention）

|编号|功能名称|描述|训练/推理|优先级|
|-|-|-|-|-|
|F5-1|RL Boss动态出题|DQN根据错题历史决策升降难度|**训练+推理**|P0|
|F5-2|变体题自动生成|对题目改数字、反转条件、插入陷阱词|纯规则|P1|
|F5-3|游戏化界面|Boss血条、注意力曲线、聚类饼图等可视化|纯展示|P1|

**F5-1 详细规格（DQN）**：

* 状态空间：3维（连续答对数，当前难度档位1\~5，卡壳标签0/1）
* 动作空间：3个（降难度/保持/升难度）
* 奖励函数：答对+1，答错-2，连续卡壳额外-1
* 模型架构：3层MLP（3→32→3）
* 探索策略：ε-greedy（ε从0.5衰减到0.05）
* 经验回放池：容量500
* 训练方式：用历史答题日志作为模拟环境
* 训练耗时：GPU约10分钟
* 决策输出：调整下一题的参数扰动幅度和陷阱词密度

**F5-2 详细规格（规则引擎）**：

* 参数扰动：正则提取数值，乘以 `random.uniform(0.5, 2.0)`
* 条件翻转：交换题干已知量与未知量
* 陷阱词注入：从F2-2反常识词库中随机抽取插入
* 筛选：通过F4-4有效性判别 > 0.6 后推送

### 4.7 跨模态融合层（L4）

|编号|功能名称|描述|训练/推理|优先级|
|-|-|-|-|-|
|F6-1|知识点-行为关联图谱|图嵌入学习知识点与卡壳行为的关联，输出认知弦图|**训练+推理**|P0|

**F6-1 详细规格**：

* 图结构：二部图（左节点=知识点簇，右节点=行为标签）
* 节点表示：`nn.Embedding` 32维可训练向量
* 训练任务：预测节点对是否有共现（点积 → Sigmoid）
* Loss：BCE
* 正样本：真实共现对（做某知识点题时同时出现卡壳标签）
* 负样本：随机采样（1:1比例）
* 训练耗时：GPU约10分钟
* 输出可视化：Plotly绘制圆形弦图（左半圆=知识点，右半圆=行为，弦粗细=关联强度）

## 十一、术语表

|术语|定义|
|-|-|
|**题目**|用户录入系统的任意一道题，无论对错，属于“全量题库”|
|**错题**|题目中用户答错的部分，是题目的子集，有专属分析流程|
|**题型聚类（F2-6）**|基于题干文本，将全量题目按知识主题/题型自动分组|
|**错因聚类（F2-4）**|基于错误答案文本，将错题按错误原因类型自动分组|
|**框选OCR**|用户手动拖拽框定题目区域，系统对该区域进行OCR识别|
|**中心词提取**|对用户提交的文章，用深度语义方法提取核心关键词|
|**卡壳**|鼠标轨迹中出现的长时间静止或小范围往复回扫|
|**过度自信**|用户自评“确定”但系统判断其行为特征符合错误倾向|
